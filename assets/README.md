# Portfolio Assets

Replace the placeholder files in these folders with your own media.

## images/
- profile image
- hero image
- general portfolio imagery

## projects/
Create one folder per project:
- tm4c-esc/
- raspberry-pi-oled/
- rc-filter/
- ropewalker/

Recommended files:
- `cover.webp`
- `01.webp`
- `02.webp`
- `schematic.webp`
- `diagram.webp`

## lab/
Use for oscilloscope captures, Pixelpulse2 screenshots, breadboard photographs, measurements, etc.

## resume/
Put the final PDF here as:
`resume.pdf`

## icons/
Optional SVG icons and logos.

The site uses graceful placeholders when media is missing, so you can upload assets later without breaking the layout.

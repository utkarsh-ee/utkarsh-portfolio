# Utkarsh Engineering Portfolio v2

Buttermax-inspired interaction direction, without copying Buttermax.

Stack: Next.js, React Three Fiber/Three.js, GSAP, responsive CSS.

Assets: add real media under `public/assets/` (images, project folders, lab, resume). Unknown personal data remains placeholders. No teaching section. No AI assistant.

## 3D interaction
The hero now contains multiple procedural 3D engineering objects: PCB, microcontroller package, motor and OLED module. They respond to pointer movement and can be rotated by dragging. No external 3D assets are required for the current scene.

# Utkarsh Portfolio

A minimal, engineering-focused static portfolio ready for Vercel.

## Structure

- `index.html` — main site
- `css/style.css` — design system and responsive UI
- `js/main.js` — mobile navigation, project detail modals, subtle reveal animation
- `assets/images/` — general imagery
- `assets/projects/` — project photos, schematics and diagrams
- `assets/lab/` — measurements and lab media
- `assets/resume/` — resume PDF
- `assets/icons/` — optional icons/logos

## Updating media

You can upload your real media later without changing the layout. Use the asset folders and then update the relevant image references in `index.html`.

The site intentionally uses placeholders for information not yet supplied. No teaching section and no AI assistant are included.

## Vercel

This is a static site. In Vercel, `Other` is sufficient and no build command is required.
